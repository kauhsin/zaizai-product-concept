# zaizai: Pet Agent — Interactive Product Concept

This repository hosts the selected public portfolio view of **zaizai: Pet Agent**, an independent Apple Watch companion-agent concept currently in pre-Alpha development.

The public page presents the product thesis, core experience principles, representative slices, high-level system relationships, and current progress. Detailed character design, behavioral rules, story content, evaluation cases, and long-term product mechanisms remain in a separate private working repository.

Live page: https://kauhsin.github.io/zaizai-product-concept/

## Status

Work in progress. The first playable Apple Watch prototype is the next milestone.
