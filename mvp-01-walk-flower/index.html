zaizai: Pet Agent · MVP 01 · Living Review V0.2

「散步中的小花」Agentic MVP 端到端体验

zaizai 的第一个可体验 MVP：用户从 App 首页与它一起开始散步；受限 LLM Agent 只判断“小花事件此刻是否应该介入”，故事选择与回忆写入仍由确定性产品流程完成。

体验闭环
首页待机 → 一起散步 → 小花事件 → 共同回忆与收藏
Agent 职责
读取结构化 Mock 情境，只决定现在介入或保持安静
设备范围
iPhone 提供完整基础体验，Apple Watch 提供增强体验

选择一条完整体验路径

一次查看一个结果分支；切换选择不会打断共同的端到端主线。

01

App 首页

先看一眼 zaizai

每次全新进入，zaizai 可能清醒，也可能正在睡觉；三个内容入口从一开始就存在。

清醒 60% 坐着看你、呼吸、眨眼、惬意摆尾，偶尔歪头。
睡眠 40% 趴睡呼吸，偶尔出现蝴蝶、骨头或气球的像素梦境，也可能自然醒来。
轻互动 点击清醒的 zaizai 出现爱心泡泡，回应后仍保持清醒；点击睡着的 zaizai 会唤醒它。

待机微循环：清醒 15 秒无操作 → 趴睡；爱心泡泡只是清醒状态的互动侧支，结束后回到清醒并重启 15 秒计时。每经过一个随机的 15–20 秒睡眠观察段，约有 35% 概率自然醒来，否则继续趴睡并进入下一个观察段。这个循环不调用 LLM。

用户也可以先打开“回忆”“小收藏”或“相册”；返回首页时恢复离开前的待机状态。

02

开始散步

点击“一起散步”，再确认一次

如果 zaizai 正在睡觉，它先柔和醒来并坐好约 0.5 秒。只有确认“开始散步”后，散步或 Workout 才真正开始。

点击“一起散步” 主入口比三个内容入口更突出。
开始确认 主按钮“开始散步”，次按钮“再想想”。
进入散步 iPhone 或 Watch 都可以发起。

选择“再想想” → 返回首页，zaizai 保持清醒，15 秒待机计时重新开始。

03

散步进行中 · Agent 幕后判断

zaizai 正在走，Agent 只决定现在要不要打扰

前台始终是穿着胸背、开心侧身行走的 zaizai；没有地点、季节或昼夜背景。页面显示 Mock 时长和“结束散步”。

展开幕后 Agent 节奏与限制
  1. 散步前 2 分钟不提示；约第 2–3 分钟，小花进入可判断阶段。
  2. 之后约每 45–60 秒出现一次内部检查机会，不持续调用 LLM。
  3. 内部结果只有 intervene_now 或 stay_silent。
  4. stay_silent 不重置可见提示之间至少 3 分钟的间隔。
  5. 每次散步最多 3 次可见主动提示；当前只有一个小花候选，所以实际最多提示一次。
04

跨端提示

iPhone 散步页上方出现小花 Banner／浮层。
Apple Watch 一次普通事件触觉，并显示高对比提示卡。

两端显示同一个事件。用户在任一端操作后，另一端同步结果或收起提示。

用户什么也不会看到 没有 Banner、触觉、空栏目或“错过了什么”的暗示；zaizai 继续正常行走。
